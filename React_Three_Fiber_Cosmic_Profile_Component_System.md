<h1>React Three Fiber Component System<br />Cosmic Profile Interaction Architecture</h1><p>This document defines the React Three Fiber (R3F) component architecture for implementing a cinematic, interactive cosmic profile page featuring a central cosmic human figure, orbital functional stars, and animated content transformations.</p><h2>1. System Overview</h2><p>The profile page is structured as a layered hybrid system:<br />• WebGL Layer (React Three Fiber scene)<br />• Interaction State Layer (Finite State Machine)<br />• UI Overlay Layer (React DOM for expanded content)</p><h2>2. High-Level Component Tree</h2><p>ProfilePage<br /> ├── Canvas (R3F)<br /> │     ├── GalaxyBackground<br /> │     ├── CosmicAvatar<br /> │     ├── OrbitalSystem<br /> │     │     ├── OrbitRing (Inner/Middle/Outer)<br /> │     │     ├── FunctionalStar (Posts)<br /> │     │     ├── FunctionalStar (Activity)<br /> │     │     ├── FunctionalStar (Friends)<br /> │     │     └── FunctionalStar (Achievements)<br /> │     ├── EnergyField<br /> │     └── CameraController<br /> ├── UIOverlay (opacity controlled)<br /> └── StateController (Reducer + Context)</p><h2>3. Core Components Description</h2><h3>3.1 GalaxyBackground</h3><p>• Multi-layer starfield with parallax.<br />• Slow nebula drift shader.<br />• Rare meteor streak particle system.<br />• Minimal bloom postprocessing.</p><h3>3.2 CosmicAvatar</h3><p>• Central humanoid mesh (GLTF model).<br />• Emissive cosmic shader with animated flow maps.<br />• Subtle breathing animation.<br />• Eye glow reactive to interaction state.</p><h3>3.3 OrbitalSystem</h3><p>• Multiple orbit radii (inner, middle, outer).<br />• Functional stars rotate slowly along orbit paths.<br />• Each star contains metadata for its function.<br />• Hover causes orbital slow-down and glow increase.</p><h3>3.4 FunctionalStar</h3><p>• Shader-based glowing sphere with particle halo.<br />• OnClick triggers state transition.<br />• Detaches from orbit and moves toward avatar hands.<br />• Transforms into UI expansion animation.</p><h3>3.5 EnergyField</h3><p>• Subtle aura shader around avatar.<br />• Intensity linked to user activity level.<br />• Pulses based on recent engagement.</p><h3>3.6 CameraController</h3><p>• Controls zoom, orbit, and focus transitions.<br />• Slight dolly-in when star selected.<br />• Smooth cubic-bezier easing curves.<br />• Prevents abrupt camera jumps.</p><h2>4. Interaction State Machine</h2><p>Primary States:</p><ul><li>IDLE – Avatar breathing, stars orbiting.</li><li>HOVER_STAR – Star glow intensifies, orbit slows.</li><li>SELECT_STAR – Star detaches from orbit.</li><li>AVATAR_INTERACT – Avatar raises hands.</li><li>STAR_TRANSFORM – Star expands or morphs.</li><li>UI_REVEAL – UIOverlay fades in.</li><li>RETURN_TO_IDLE – UI closes, star re-enters orbit.</li></ul><h2>5. Animation Flow Example (Posts Star)</h2><p>1. User clicks Posts star.<br />2. Orbital rotation slows.<br />3. Star detaches and animates to avatar hands.<br />4. Avatar performs subtle pluck gesture.<br />5. Star expands into luminous energy sphere.<br />6. Sphere morphs into UIOverlay (posts grid).<br />7. Background dims slightly for focus.</p><h2>6. Rendering &amp; Performance Considerations</h2><p>• Use GLTF compression (DRACO) for avatar model.<br />• Limit postprocessing effects.<br />• Cap particle count.<br />• Use instanced meshes for stars.<br />• Separate animation state from routing logic.</p><h2>7. Double-Click Collapse</h2><p>Double-click anywhere triggers accelerated return animation.<br />Star reforms and re-enters orbit.<br />UIOverlay fades out smoothly.</p><p><br />End of Document</p>
