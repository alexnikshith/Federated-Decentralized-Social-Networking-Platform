<h1>React + Three.js Cinematic Login Transition<br />State Machine Architecture</h1><p>This document defines the architectural structure for implementing a cinematic login transition using React and Three.js (or React Three Fiber). The design ensures proper scene orchestration, lifecycle control, UI layering, and seamless transition from WebGL to DOM.</p><h2>1. High-Level Architecture Overview</h2><p>The system is divided into three major layers:<br />• Authentication Layer<br />• Animation State Machine Layer<br />• Rendering Layer (WebGL + DOM)</p><h2>2. Core State Machine Design</h2><p>The animation must be controlled by a deterministic finite state machine to prevent abrupt scene cuts and lifecycle conflicts.</p><ul><li>Primary States:</li><li>IDLE – Login screen visible</li><li>WORMHOLE_INIT – Distortion and wormhole formation</li><li>WORMHOLE_TRAVEL – Camera traversal through volumetric tunnel</li><li>WHITE_FLASH – Full white screen masking scene switch</li><li>GALAXY_REVEAL – Galaxy scene with target planet</li><li>PLANET_APPROACH – Orbital deceleration toward planet</li><li>ATMOSPHERIC_ENTRY – Fog density increases, planet diffuses</li><li>UI_GHOSTING – Dashboard mounted at 0 opacity with wireframe glow</li><li>UI_SOLIDIFY – Dashboard opacity increases, fog dissipates</li><li>COMPLETE – WebGL unmounted, dashboard fully interactive</li></ul><h2>3. React Component Architecture</h2><p>App<br /> ├── AuthProvider<br /> ├── TransitionController (State Machine Manager)<br /> │     ├── WormholeScene (Three.js)<br /> │     ├── GalaxyScene (Three.js)<br /> │     ├── AtmosphericOverlay (Shader/Fog Layer)<br /> │     └── WhiteFlashOverlay (DOM Layer)<br /> └── Dashboard (Pre-mounted, controlled via opacity)</p><h2>4. Lifecycle Flow</h2><p>1. User authenticates.<br />2. TransitionController switches state from IDLE to WORMHOLE_INIT.<br />3. Dashboard component preloads but remains hidden (opacity: 0).<br />4. State transitions sequentially via controlled timers or animation callbacks.<br />5. During UI_SOLIDIFY, dashboard opacity increases progressively.<br />6. WebGL scene unmounts only after dashboard reaches full opacity.<br /></p><h2>5. Double-Click Skip Logic</h2><p>Double-click event triggers accelerated state progression.<br />Instead of skipping directly to COMPLETE, interpolate animation progress to final state with reduced duration curves.<br />Ensure no abrupt component unmounts.</p><h2>6. Rendering Best Practices</h2><p>• Use GPU acceleration (Three.js / React Three Fiber).<br />• Use physically-based materials for planet (albedo, normal, specular maps).<br />• Use volumetric fog shaders for atmospheric entry.<br />• Use bloom postprocessing for white-core expansion.<br />• Keep WebGL canvas mounted until UI is fully visible.<br /></p><h2>7. Performance &amp; Safety</h2><p>• Preload dashboard data during wormhole travel phase.<br />• Cap frame rate if necessary for mid-tier GPUs.<br />• Provide reduced-motion mode with simplified fade transition.<br /></p><p><br />End of Document</p>
