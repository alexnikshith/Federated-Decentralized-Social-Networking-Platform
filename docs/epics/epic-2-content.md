# EPIC 2: Content Sharing & Social Interaction

## Goal
Allow users to create and view content within their local instance while
preparing the system for federated content exchange.

---

## Features
- Create text-based posts
- View a local chronological feed
- Delete own posts

---

## Design Decisions
- Content is stored locally per instance
- Feed ordering is chronological
- Post deletion is ownership-based

---

## Phase 1 Scope
- Local posts only
- No likes or comments

---

## Planned Extensions
- Likes and comments
- Engagement analytics
