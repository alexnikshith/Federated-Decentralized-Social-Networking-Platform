Production Specification: Realistic Cosmic Human GLTF Model

This document defines the complete technical and visual specification for creating a high-quality, realistic cosmic human model suitable for use in React Three Fiber / Three.js environments. The model must feel cinematic, ethereal, and astrophysically inspired while maintaining anatomical realism.

1. Artistic Direction

The cosmic human should appear as a luminous, galaxy-infused humanoid entity. The body must maintain realistic anatomical proportions and subtle facial detail, while the surface contains flowing nebula energy, embedded starfields, and soft emissive gradients. The aesthetic should feel elegant and celestial — not cartoonish, not over-saturated, and not game-like.

2. Base Mesh Requirements

• Realistic humanoid proportions (neutral pose)
• Polycount target: 25k–60k triangles
• Clean quad topology
• Proper UV unwrapping
• Separate mesh groups for body, eyes, and hair-energy layers
• No exaggerated stylization

3. Material & Shader Structure

The model must use layered PBR materials with emissive enhancement:

A. Base Skin Layer
• Deep indigo / midnight blue base color
• Roughness: ~0.5–0.7
• Metalness: minimal (0.05–0.15)

B. Emissive Nebula Layer
• Animated noise-based flow map
• Gradient mapping (cyan → violet → soft gold)
• Emissive intensity adjustable (1.5–3.0)

C. Starfield Overlay
• High-resolution masked texture
• Additive blending
• Subtle twinkle variation

D. Rim Glow (Fresnel Effect)
• Soft cyan atmospheric edge lighting
• Intensity increases with camera angle

4. Hair / Energy Crown Design

Hair must be represented as flowing nebula energy rather than physical strands:
• Curved plane geometry with alpha textures
• Emissive gradient
• UV distortion animation for slow energy flow
• Optional particle emission nodes

5. Eyes & Facial Energy

• Eyes fully emissive (soft white or cyan glow)
• Bloom-compatible materials
• Very subtle pulsation animation
• No cartoon exaggeration

6. Required Animation Clips

Include the following animation clips:
• Idle_Breath (subtle chest movement)
• Energy_Pulse (torso glow variation)
• Hand_Raise (for star interaction)
• Neutral_Pose_Hold
Animations must be smooth and subtle.

7. Export Requirements (Blender → GLTF)

• Format: GLTF 2.0 (.gltf + .bin)
• Include animations
• Include normals and tangents
• Use PBR workflow
• Enable DRACO compression
• +Y Up, -Z Forward
• Separate texture files (PNG or JPG)
• Keep total model size optimized for web use

8. Performance Constraints

• Texture resolution target: 2K maximum
• Keep shader complexity optimized
• Avoid excessive particle counts
• Ensure compatibility with React Three Fiber


End of Specification
